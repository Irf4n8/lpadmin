4. CRITICAL GOTCHAS FOR AI AGENTS:
   - Cross-Origin Fetch in Playwright: Calling `fetch()` inside a bare `page.evaluate()` on `about:blank` will fail due to CORS. Always use Playwright's native `context.request.post(...)` or navigate `page.goto()` to the target origin first.
   - Admin Login LocalStorage: After submitting the login form, the page asynchronously stores `oms_admin_token` in `localStorage`. Wait for the response or function `() => !!localStorage.getItem('oms_admin_token')` before issuing subsequent admin API calls.
   - Instances: BlackTrader maintains separate instances for trading (`paper` and `real`). New accounts start with 1,000,000 default paper balance; setting balance requires an explicit POST to the balance endpoint.
